The learning path

One live hour. Monday, Wednesday, Friday. Repeated until solid.

We teach military members, veterans, and their families in Killeen, Texas. Progress means demonstrating a skill, not surviving a deadline: a missed check means we re-teach it. That is the no-flunk-out policy, stated as fact rather than slogan.

Inside one hour

Our default session plan — we publish a real session log once cohorts run:

  1. Recap & questions — 10 minutes. Last session’s skill, retried cold, and questions before any new material.
  2. Guided build — 35 minutes. Everyone works the same real task while instructors circulate instead of lecturing.
  3. Demonstrate & log — 15 minutes. One learner shows the work; everyone logs what held up and what needs a repeat.

The readiness standard

“Explain it in your own words. Do it on a fresh example. Handle one variation. Privately, untimed, repeated until solid — a miss means we re-teach, not that you failed.”

After foundations: the core path

Core · 4–6 weeks12–18 live hours

AI foundations and safe use

The six-week syllabus above, paced to the cohort. Use an AI tool for a real task, learn privacy basics, source checking, and when a person should make the decision.

Core · 6–8 weeks18–24 live hours

Prompting, research, and verification

Turn a vague request into a clear brief, compare outputs, trace sources, and revise based on evidence.

Core · 6–8 weeks18–24 live hours

Reusable assistants, skills, and current plugins

Organize instructions, examples, tests, knowledge, and tool access. Learn how today’s publishing routes differ from older GPT and plugin formats.

Core · 4–6 weeks12–18 live hours

Career project and portfolio clinic

Map job descriptions to evidence, write a truthful case study, explain tradeoffs, and practice an interview based on work you actually completed.

Core planning range: 20–28 instructional weeks

That equals 60–84 live hours before repeats, breaks, absences, or prerequisite support. It is a planning range, not a promised graduation date.

What ends up in a portfolio

  • Task briefs that produced checked results
  • Workflows documented well enough for someone else to run
  • One documented skill or small assistant, with test cases
  • One truthful case study: task, approach, tradeoffs, results

Optional advanced paths

APIs and connected workflows

12–16 weeks36–48 live hours

Agents, tools, and retrieval

Bounded permissions, trusted knowledge, checkpoints, recovery, and human review for consequential actions.

12–16 weeks36–48 live hours

Evaluation, replay, and reliable improvement

Baselines, held-out cases, point-in-time replay, leakage, contamination, reward hacking, overfitting, and honest comparison.

We teach replay, leakage, contamination, reward hacking, and backtesting so learners can detect and prevent them. Every learner signs the same commitment in the community agreement: evaluation methods find weaknesses — they never manipulate scores or deceive people.

A learner pursuing every optional path would plan for roughly 54–74 instructional weeks and 162–222 live hours, often longer. You do not need every track to benefit.
