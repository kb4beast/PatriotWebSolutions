Learning paths

Practical skills, taught at a human pace.

Every module combines a real task, supported practice, a private readiness check, and something you can show in a portfolio. The schedule is three live hours per week. Repetition and breaks extend the calendar whenever needed.

Core · 4–6 weeks12–18 live hours

AI foundations and safe use

Use an AI tool for a real task. Learn privacy basics, source checking, common failure patterns, and when a person should make the decision.

Build: a checked everyday workflow and a short safety guide.
Core · 6–8 weeks18–24 live hours

Prompting, research, and verification

Turn a vague request into a clear brief, compare outputs, trace sources, and revise based on evidence.

Build: a reusable task brief and source-check checklist.
Core · 6–8 weeks18–24 live hours

Reusable assistants, skills, and current plugins

Organize instructions, examples, tests, knowledge, and tool access. Learn how today’s publishing routes differ from older GPT and plugin formats.

Build: a documented skill or small assistant with test cases.
Core · 4–6 weeks12–18 live hours

Career project and portfolio clinic

Map job descriptions to evidence, write a truthful case study, explain tradeoffs, and practice an interview based on work you actually completed.

Build: a portfolio case study and skills-to-job map.

Core planning range: 20–28 instructional weeks

That equals 60–84 live hours before repeats, breaks, absences, or prerequisite support. It is a planning range, not a promised graduation date.

Optional advanced paths

10–14 weeks · 30–42 hours

APIs and connected workflows

Structured data, test credentials, error handling, rate limits, cost controls, and safe connections between tools.

12–16 weeks · 36–48 hours

Agents, tools, and retrieval

Bounded permissions, trusted knowledge, checkpoints, recovery, and human review for consequential actions.

12–16 weeks · 36–48 hours

Evaluation, replay, and reliable improvement

Baselines, held-out cases, point-in-time replay, leakage, contamination, reward hacking, overfitting, and honest comparison.

A learner pursuing every optional path would plan for roughly 54–74 instructional weeks and 162–222 live hours, often longer. You do not need every track to benefit.
