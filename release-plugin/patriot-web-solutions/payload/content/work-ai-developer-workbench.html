What it was

A developer-support assistant, built as a custom GPT during the period when custom GPTs were the practical route for shipping assistant tools. The full feature history lives with the builder’s records, and this page states only what that history establishes without embellishment.

What it taught us

  • Recorded 2026-09-15: platform-hosted tools live at the platform’s pleasure — an assistant is not yours the way a repository is. Our flagship work is now MIT-licensed in the open.
  • Recorded 2026-09-15: a tool whose behavior you cannot replay is a tool you cannot honestly evaluate. Verification-first design became the requirement, not the afterthought.
  • Recorded 2026-09-15: “it worked for me” is not a record. Every current project keeps evidence a stranger could check.

What publication requires

  3. Publish with limits documented — the same standard every current project meets.
