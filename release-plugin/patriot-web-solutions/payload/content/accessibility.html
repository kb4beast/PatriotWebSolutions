Accessibility

Access is part of the work.

Patriot Web Solutions aims for content and interactions that work with keyboards, screen readers, zoom, reduced motion, captions, and common mobile devices. We use clear structure, visible focus, readable contrast, text alternatives, and plain instructions as baseline practices. Our working target is WCAG 2.2 AA; we claim conformance only when testing supports it.

Ask for help or report a barrier

Email support@patriotwebsolutions.org or call (254) 761-5991. Tell us the page, what you were trying to do, and the browser or assistive technology if you are comfortable sharing it. Do not include medical details in a public form. We provide a private channel when more information is needed.

Ongoing review

Automated checks help find some barriers; they do not replace testing with people. This release’s automated checks cover WCAG A/AA rules on every public page, plus keyboard focus visibility, reduced-motion support, and small-screen layout; the results ship with the release receipts. We date material improvements and known limitations as testing continues.
