Accessibility

Access is part of the work.

Patriot Web Solutions aims for content and interactions that work with keyboards, screen readers, zoom, reduced motion, captions, and common mobile devices. Our working target is WCAG 2.2 AA; we claim conformance only when testing supports it.

Baseline practices

  • [pws_icon name="check"]Clear structure with one heading hierarchy per page and a skip link
  • [pws_icon name="check"]Visible keyboard focus on every control, in the accent color
  • [pws_icon name="check"]Text at 4.5:1 contrast or better against the dark ground; 44px minimum control height
  • [pws_icon name="check"]Text alternatives for images; no information carried by color alone
  • [pws_icon name="check"]Reduced-motion and print styles; tables that reflow on small screens
  • [pws_icon name="check"]No remote fonts, analytics, or advertising scripts in this release

Ask for help or report a barrier

Email support@patriotwebsolutions.org. Tell us the page, what you were trying to do, and the browser or assistive technology if you are comfortable sharing it. Do not include medical details in a public form. We provide a private channel when more information is needed.

Ongoing review

Automated checks help find some barriers; they do not replace testing with people. Before this release ships to production, every public route is checked on desktop and mobile with keyboard-only navigation and 200% zoom, as listed in the release’s install checklist. We date material improvements and known limitations as testing continues.
